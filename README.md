# DATA-ANALYST-PROJECT-RANGANATHAN-R
This repository contains a data analytics project, including datasets, preprocessing, EDA, visualizations, and insights using Python.

Social Media User Behavior Analysis – Project Description
Developed an end-to-end Social Media User Behavior Analysis project using Python, Pandas, NumPy, Matplotlib, Seaborn, and Power BI.
Performed data cleaning and preprocessing by handling duplicates, converting date columns, and creating derived features such as account age and engagement score.
Conducted Exploratory Data Analysis (EDA) to identify user behavior trends, platform engagement patterns, device preferences, and spending habits.
Built interactive Power BI dashboards with KPI cards, bar charts, donut charts, treemaps, gauges, and user-level analysis visuals for business reporting.
Analyzed correlations between daily social media usage, engagement metrics, mental health scores, and sleep disruption patterns.
Identified key insights such as:
Instagram and TikTok having the highest engagement.
Younger users dominating social media activity.
Heavy social media usage impacting mental wellbeing and sleep cycles.
Created visualizations including:
Age distribution analysis
Gender distribution
Platform usage comparison
Usage vs mental health scatter plots
Correlation heatmaps
Profession vs usage analysis
Designed actionable recommendations for businesses to improve targeted marketing strategies and optimize campaigns for mobile-first users.
Exported cleaned datasets and structured the workflow into:
Data Cleaning
Feature Engineering
EDA
Data Visualization
Insights & Recommendations.
Demonstrated practical skills in data analysis, storytelling, dashboard development, and business insight generation through a real-world behavioral dataset.
